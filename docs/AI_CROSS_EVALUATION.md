# 第二模型 AI 交叉评价：不能代替人工真值

> 2026-11-16 更新：后续协议采用双模型评分，当前采用[双模型 v2 协议](DUAL_MODEL_V2.md)。本文保留 2026-11-13 批次历史；其中“人工待完成”不再是当前交付要求。旧文件不改名为人工结果。

原探索实验后增加 kimi-k3 第二模型裁判，使用已配置的 DashScope 兼容端点；这里只记录请求的模型标识，不根据名称证明模型内部实现、训练来源或独立性。API 返回内容及用量以本地原始记录为准。

没有连接外部真人评分插件，也没有招募真实标注者。AI 可以辅助评分，但不能称为“模拟真人产生的客观人工评分”。评分模板中的 human_attested 保持 false，AI 结果与真人文件存放在不同目录。人工原始表、声明和分歧分析流程仍保留。

## 实验设计

- 输入是既有 10 篇原稿和实际产出的消融文本；按题目与文本完全相同去重，合计 16 篇。没有重新生成失败的消融文本。
- 每篇一次调用，同时输出四维；评分锚点与 rubric-v3 内容一致，但原模型是每维单独调用，第二模型是联合四维调用，因此模型差异与提示布局差异不能分离。
- 评分前不发送原分数、消融条件、反馈、设计层次或来源模型名；文章本身可能暴露风格，不能保证完整盲法或消除偏差。
- 额外授权最多 50 次，本次计划只需 16 次；每篇最多尝试 1 次，180 秒超时，输出上限 4096 token。任意 provider_error 即停止，不自动换模型、不重试、不扩大预算。
- 每个维度仍需严格 JSON 数值、解释、具体建议和逐字匹配的原文引用；解析失败保留，不当成零分。
- 接收到 AI 评分只证明该请求成功，不证明其判断正确。不同模型标识、不同提供商或两模型一致也不能证明客观性。

## 报告解读

AI_ONLY_REPORT.json 中：

- ai_vs_original_model_agreement_not_accuracy：对每篇原稿先平均原模型重复评分，再与第二模型比较 MAE 与 Spearman，以及以原稿为单位的探索性 bootstrap 区间。这里 MAE 是模型分歧，不是对人工真值的误差；Spearman 是排序一致性，不是准确率。
- primary_ai_comparison_all_feedback_vs_no_feedback：仅比较两组工作流成功且有第二模型评分的同样本配对。失败/缺失/未评分配对另计，不用原稿残留冒充重写成功。
- human_reference_metrics 与 human_inter_rater_agreement：保持 null，没有人类评分就不计算“人工一致性”。
- 真实人工 MAE、Spearman、ICC 仍由 src.annotation 读取真实完成的标注文件后计算。

原探索消融在后半段出现大量 DNS 解析失败：只剩 7/40 工作流成功，主比较可用工作流配对仅 1 篇。即使第二模型给出某个差值，也无法支持稳定的消融效果结论，少于两个有效样本不生成差值置信区间。不能将单个成功配对推广到 10 篇或完整系统。
