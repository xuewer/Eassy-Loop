# 人工参考和盲评规范

## 两种标注目的

可信度实验对固定原文建立独立人工参考，放入数据集 human_scores；这些标签只进入离线统计，不进入模型提示词。每篇重复 K 次，先平均模型分数，再与人工参考计算各维 MAE、Spearman。无参考不报告准确性，常数序列或样本不足相关系数为 null。原文内标准差只衡量稳定性。

修订效果需要对各变体最终文章进行独立盲评，不能用同一模型给自己的评分增长代替质量提升。

## Rubric（0–1）

共同锚点：0=标准缺失；.25=重大缺陷；.5=部分满足但有明显遗漏；.75=有效且有明确局限；1=卓越且无实质缺陷。允许中间分，不因语言流畅就满分。

| 维度 | 重点 | 避免 |
|---|---|---|
| relevance | 持续回应题目、覆盖核心要求 | 出现关键词即高分 |
| grammar | 语法、句法、用词与清晰度 | 把个人风格偏好当语法错误 |
| structure | 中心论点、段落作用、逻辑、衔接与结论 | 把句子流畅当组织合理 |
| depth | 因果机制、具体案例、论据、反方与局限 | 奖励空泛断言、编造引用或篇幅 |

默认权重 .3/.2/.2/.3 是工程设置，未人工校准。只在 dev 调整 prompt、权重或退出阈值，不用 test 调参。

## 操作

1. 使用有权使用、覆盖主题/质量层次的文本，按主题或来源划分 dev/test，避免近似文本泄漏。
2. 建议两名独立标注者先校准少量 dev 文本，保存每人原始评分、分歧和裁决，不根据模型结果反向修改标签。仅一名标注者时明确局限。
3. 参考标签需四维完整；不得把模型自评分填作人工标签。保存原始记录和版本。
4. export-blind 生成 annotation.jsonl 和 private_mapping.json。只把 annotation.jsonl 与本规范交给标注者；映射和模型输出留在研究方。
5. 保留 blind_id、topic、essay 原样，只填写 scores 的四个 null。多位标注者保存独立副本，当前分析入口读取最终裁决的一份标签。
6. analyze 检查文本、题目、哈希、重复或未知盲评编号。缺失标签不补分；报告标注覆盖与有效配对数。

导出随机打乱行顺序，隐藏变体与 sample_id；相似文章仍可能被识别，不能宣称完全盲法。控制呈现顺序，避免告知哪篇是改进稿。

## 报告

同时报告计划/完成/成功/标注数和失败原因，不只展示成功案例。重复差值先按样本平均，再按样本配对 bootstrap；同一篇重复调用不是独立样本。报告人工加权分差、改善/退化比例和区间，不将分差写成准确率提升。

src.annotation 已支持一至两位真人评分：保留逐项分歧，并计算双人 MAE、Spearman 与绝对一致性 ICC(A,1)/(A,2)。空模板不能参与统计。未实现外部事实核查、多重比较校正或任意多标注者模型。小样本、单标注者和同模型自评偏好均需如实说明。当前双模型协议见 [DUAL_MODEL_V2.md](DUAL_MODEL_V2.md)。
